# 🚛 Transportes Web

Sitio web institucional desarrollado para **Transportes X**, con el objetivo de presentar la empresa, comunicar sus servicios de transporte y facilitar el contacto con potenciales clientes.

## 📌 Descripción del proyecto

Transportes Web es un sitio web informativo que permite a los visitantes conocer la empresa, explorar sus diferentes servicios de transporte, consultar información institucional y comunicarse mediante un formulario de contacto.

El proyecto fue desarrollado como práctica de diseño y desarrollo web, integrando estructura HTML, estilos CSS y procesamiento de formularios con PHP.

## ✨ Funcionalidades

- **Inicio:** presentación general de la empresa.
- **Nosotros:** sección institucional para conocer la organización.
- **Servicios:** información sobre transporte marítimo, aéreo y ferroviario.
- **Galería:** espacio destinado a mostrar imágenes relacionadas con la actividad.
- **Novedades:** sección de publicaciones e información de interés.
- **Contacto:** formulario para enviar consultas, junto con los datos de contacto de la empresa.

## 🛠️ Tecnologías utilizadas

- HTML5 – Estructura y contenido del sitio.
- CSS3 – Diseño, estilos y organización visual.
- Normalize.css – Normalización de estilos entre navegadores.
- Google Fonts – Tipografía Open Sans.
- PHP – Procesamiento del formulario de contacto.
- PHPMailer – Gestión del envío de correos electrónicos.

## ⚙️ Instalación y ejecución local

1. Descargar o clonar el repositorio.
2. Colocar la carpeta del proyecto dentro de `htdocs` de XAMPP.
3. Iniciar Apache desde el panel de control de XAMPP.
4. Abrir el navegador y acceder a:

```text
http://localhost/transportes-web/
```

Para utilizar el formulario de contacto es necesario tener configurado PHP y el servicio SMTP utilizado para el envío de correos electrónicos.

**Importante:** las credenciales de correo deben mantenerse privadas y nunca publicarse en GitHub.
